liblogos · Electron PoC

Three ways to reach the Logos delivery module, side by side. Load only uses liblogos_core's C ABI and stops there — it cannot call the module. via logosctl drives a daemon beside the app through its core_service gateway. in-process calls the module from the addon itself, with no daemon at all. The last two both start a real Waku node; see the README for what each one proves.
